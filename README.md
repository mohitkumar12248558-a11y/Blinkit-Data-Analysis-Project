# 📊 Blinkit Sales Data Analysis & Dashboard

An end-to-end data analysis and interactive Power BI dashboard project evaluating Blinkit's grocery sales, customer ratings, item visibility, and outlet performance.

---

## 🚀 Project Overview
The objective of this project is to analyze Blinkit's sales data to uncover key business insights, understand sales patterns across different outlet types, and help improve inventory and delivery strategies.

---

## 🛠️ Tools & Technologies Used
* **Power BI:** Interactive Dashboards, KPI Cards, Slicers, Visualizations
* **Microsoft Excel:** Data Cleaning, Transformation, Exploratory Data Analysis (EDA)
* **Python & SQL:** Data exploration and querying

---

## 📈 Key Insights & Features
* **Sales Performance:** Breakdown of total sales across outlet locations (Tier 1, Tier 2, Tier 3) and types.
* **Product Analysis:** Top-selling item types, fat content analysis (Low Fat vs Regular), and average ratings.
* **Outlet Performance:** Analysis of sales based on outlet establishment year and outlet size.
* **Interactive Dashboard:** Slicers for item types, outlet location, and outlet size for real-time data filtering.
